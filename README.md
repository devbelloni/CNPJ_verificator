# CNPJ Verificator (Desktop App)

A small Tkinter desktop app that looks up a Brazilian company by **CNPJ** (corporate tax
ID) through the public [BrasilAPI](https://brasilapi.com.br) service and shows its legal
name, main activity, address, city, state, ZIP code and phone number.

## Run it

```bash
pip install -r requirements.txt
python main.py
```

Enter a CNPJ (with or without punctuation) and click the check button.

## Stack

Python, Tkinter, `requests`, BrasilAPI.
